# Catalyst Repo Structure & Package Map

## The five packages

| npm name | directory | what it is |
|---|---|---|
| `@haiilo/catalyst-tokens` | `tokens/` | Style Dictionary source → CSS custom properties, SCSS vars, JSON, JS exports |
| `@haiilo/catalyst` | `core/` | Stencil web components — source of truth for all component logic and markup |
| `@haiilo/catalyst-angular` | `angular/projects/catalyst/` | Angular wrappers — auto-generated by Stencil's angular-output-target during core build |
| `@haiilo/catalyst-angular-formly` | `angular/projects/catalyst-formly/` | ngx-formly field types for Catalyst components |
| `@haiilo/catalyst-react` | `react/` | React wrappers — auto-generated by Stencil's react-output-target during core build |

## Dependency graph

Build order is strict. `core` must be built before Angular or React wrappers
because Stencil's build writes the wrapper source files.

```
tokens/
  └─→ core/                    (consumes token SCSS variables)
        ├─→ angular/            (proxies.ts auto-generated by stencil build)
        │     └─→ angular-formly/
        └─→ react/              (stencil-generated/index.ts auto-generated)
```

## Auto-generated files — never edit by hand

```
angular/projects/catalyst/src/lib/directives/proxies.ts
react/src/components/stencil-generated/index.ts
```

Both are regenerated on every `pnpm run build:core`. Edits will be overwritten.

Every `@Prop()`, `@Event()`, and `@Method()` in a Stencil component
automatically becomes an Angular `@Input()` / `@Output()` and a React prop —
no manual wiring required.

## Key build commands

| command | what it does |
|---|---|
| `pnpm run build` | Full pipeline: tokens → core → angular → angular-formly → react |
| `pnpm run build:tokens` | Tokens only |
| `pnpm run build:core` | Core only — also regenerates Angular and React proxy files |
| `pnpm --filter @haiilo/catalyst run start` | Stencil dev server with hot reload at `localhost:3333` |
| `pnpm --filter @haiilo/catalyst run test` | Unit tests (Vitest, no browser) |
| `pnpm --filter @haiilo/catalyst run test:screenshot` | Visual regression (Playwright + pixelmatch) |
